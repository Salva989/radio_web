# Chrome to AzuraCast Checklist

- [ ] Docker stack is running: `docker compose ps`
- [ ] AzuraCast opens at `http://localhost`
- [ ] Live broadcasting is enabled on the station
- [ ] Streamer/DJ user exists in AzuraCast
- [ ] Chrome output is set to `CABLE Input`
- [ ] BUTT audio input is set to `CABLE Output`
- [ ] BUTT server type is `IceCast`
- [ ] BUTT host is `localhost`
- [ ] BUTT port matches the station live/broadcasting port
- [ ] BUTT mount matches the AzuraCast station mount
- [ ] BUTT connects successfully
- [ ] AzuraCast now playing shows live input
