# Owncast Decision

Skip Owncast unless you need one of these:

- video streaming alongside radio
- reactive visuals or overlays for live shows
- chat + stream page for hosts or events

If you do need it later, run Owncast separately and feed it:

- a visual scene from OBS
- the same program audio used for AzuraCast live input

Keep AzuraCast as the audio automation and radio backend. Use Owncast only as the video-facing layer.
